## Sobre o Projeto

As primeiras 48 horas de um desaparecimento são as mais cruciais para um desfecho positivo. Atualmente, a comunicação depende muito de redes sociais e carece de segmentação geográfica rápida. 

O **SpotLink** (nome provisório) é uma plataforma colaborativa focada em centralizar alertas de desaparecimento. O sistema notifica cidadãos que estejam próximos ao local do último avistamento, criando uma rede de buscas ágil e integrada para auxiliar as autoridades e as famílias.

## Backlog e Funcionalidades Previstas

* **Gestão de Identidade:** Cadastro de usuários (cidadãos e policiais) com validação (ex: CPF) para inibir informações falsas.
* **Mural de Alertas (Feed):** Exibição em tempo real de pessoas desaparecidas na região do usuário (ex: Chapecó e arredores).
* **Notificações Georreferenciadas (Push):** Alertas disparados para celulares em um raio específico (ex: 10km) do último avistamento.
* **Reporte de Pistas (Spotting):** Botão rápido para envio de fotos, localização ou descrições (de forma anônima ou identificada) diretamente para os responsáveis.
